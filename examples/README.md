# Examples

This directory contains executable code examples showing how to use the `@aetherwave/aether-agent-sdk`.

## Files

- [`basic-agent.ts`](./basic-agent.ts): Demonstrates creating an agent with policy rules and evaluating actions.
- [`stellar-payment.ts`](./stellar-payment.ts): Demonstrates preparing and submitting a USDC payment on Stellar Testnet.
- [`evm-query.ts`](./evm-query.ts): Demonstrates querying balance and smart contract state on an EVM network.

## Running Examples

```bash
# Execute with your favorite TS runner
npx tsx examples/basic-agent.ts
npx tsx examples/stellar-payment.ts
npx tsx examples/evm-query.ts
```
